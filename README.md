# GProg World
<br>
<br>
It is a fully integrated Q&A social networking template inspired by Quora.
<br>
It allows users to ask and answer questions, interact with content, and follow topics.
<br>
It was built with the goal of creating an interactive, easy-to-use knowledge community.
<br>
<br>
<a style="font-size:50px;" href="http://gprog-social-platform.infinityfreeapp.com/">Go to Live Demo<a/>
<br>
<br>
Project Features:
<br>
The template is very easy to understand and modify. Simple, easy-to-use code is used for both beginners and professional developers.
<br>
<br>

Technologies Used:
<br>
Frontend: HTML, CSS, JavaScript, Bootstrap, JQuery, React
<br>

Backend: PHP
<br>

Database: MySQL
<br>

PHP Sessions
<br>
<br>

Project Implementation:
<br>

Download the project files or create a clone.
<br>

Copy the files into a local server folder (such as htdocs in XAMPP).
<br>

Create a database and import the gprog.sql file into the database folder.
<br>

Update the database connection information in the connect.php file in the fun folder.
<br>

The website is now ready.
